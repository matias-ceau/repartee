# 17 février 2020

Rendez-vous chez le Dr Benali ce matin. Le mot est posé : migraine avec aura. Les zigzags dans l'œil gauche, la main qui fourmille, puis le mal de tête qui arrive comme un train. Ce n'était donc pas "juste la fatigue".

Il m'a prescrit du sumatriptan, à prendre dès les premiers zigzags, pas une heure après en espérant que ça passe. Il m'a demandé de tenir un carnet. Je l'ai commencé dans [[Migraine]].

Ce qui revient : les nuits trop courtes, le vin rouge, les semaines de rendu. Autrement dit ma vie depuis septembre.

Bizarrement je suis soulagée. Un nom, un protocole, un carnet. Je sais faire avec ça.
